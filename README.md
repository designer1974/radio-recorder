# Devoo Recorder

Registratore audio avanzato per Android (Flutter + Kotlin).

- Audio **interno** (es. Radio Garden) o **microfono**, WAV stereo 48 kHz
- **Riduzione rumore**
- **Bandiera automatica** nel titolo: "Fox News usa" → 🇺🇸
- Lista registrazioni con filtro per bandiera, ascolto, **rinomina**, **elimina**
- **Condividi** su WhatsApp, email, ecc.

## Scaricare l'app
Ogni modifica su `main` compila l'APK in automatico (GitHub Actions).
Scaricalo dalla pagina **Releases** → `RadioRecorder.apk`.

Richiede Android 10 o superiore.
